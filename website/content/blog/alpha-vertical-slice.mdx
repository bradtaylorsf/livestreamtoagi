# Alpha as the Vertical Slice

This research note is backdated to 2026-05-20, the point in the repository
history when this part of the system became concrete enough to write about.

## Research Question

Can one agent complete a small embodied loop through every load-bearing system?

## System Move

Alpha got a profile, errand verbs, poll/complete bridge calls, verified world action,
memory writes, Management review, cost gate participation, and an acceptance report.

## Evidence

- E7 issues #565-#571 tracked the Alpha vertical slice.
- .alpha-loop summary `session-summary-session-epic-509-epic-e7-alpha-vertical-slice.md` documents evidence freshness and contract-first bridge verbs.
- `docs/minecraft/alpha-slice-report.md`, `docs/minecraft/alpha-profile.md`, and `docs/minecraft/alpha-errand.md` capture the slice.

## What Broke

A stale acceptance artifact can be worse than no artifact. Evidence freshness had to
become part of the gate.

## Why It Matters

The signal is vertical-slice discipline: prove one narrow path end to end before
broadening.

## What Changed Next

The next expansion was all-agent embodiment and a move away from one central director.
